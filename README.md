## Welcome!

## Getting started
### Android Studio
Download the latest version of Android Studio from https://developer.android.com/studio and follow the installation instructions. 
When Android Studio loads up, click clone repository and paste the link of this page into that and you're done!
Make sure to pull for the latest releases and push what you work on to the development branch!
